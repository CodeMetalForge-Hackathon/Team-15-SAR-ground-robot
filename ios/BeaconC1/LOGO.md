# Rescue Signal logo

Created with the built-in image generation tool. The orange location pin and radio arcs represent a phone broadcasting its location. The asset catalog uses the same mark for the iPhone app icon and in-app header. The source output was resized to 1024 × 1024 for the iOS app icon, with no alpha channel.

## Generation prompt

Use case: logo-brand. Create one final production iOS app icon for Team-15 Rescue Signal, a phone beacon app paired with a search-and-rescue operator dashboard. A beautifully simple, precise geometric orange location-pin/beacon symbol with two symmetrical radio signal arcs, combining location and broadcasting into ONE coherent bold mark. Flat vector-like artwork, very few shapes, thick consistent strokes, easily understood and recognized at tiny size. Orange #f0701e mark on solid nearly-black charcoal #0b0b0c full-bleed square background. Centered optically balanced composition, mark occupies about 60% of square, generous safe padding. No lettering, no numbers, no gradients, no texture, no shadow, no 3D, no mockup, no border, no rounded outer corners (iOS masks corners). Output single square 1024x1024 icon.
